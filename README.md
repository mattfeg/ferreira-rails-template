# Ferreira Rails Template

A modern Rails 8 template with all the essentials for building scalable applications.

## 🚀 Features

- **Testing**: RSpec, Shoulda Matchers, SimpleCov (code coverage)
- **Authentication**: Devise
- **Authorization**: Pundit
- **Database**: PostgreSQL with Docker Compose
- **Styling**: Tailwind CSS
- **Development Tools**: Letter Opener (email preview), dotenv-rails
- **Fake Data**: Faker gem
- **Git**: Automatic repository initialization with initial commit

## 🎯 Quick Start

### 1. Create a new Rails app with this template

```bash
rails new myapp \
  -d postgresql \
  -c tailwind \
  -m https://raw.githubusercontent.com/mattfeg/ferreira-rails-template/main/template.rb
```

### 2. Navigate to your app

```bash
cd myapp
```

### 3. Start PostgreSQL

```bash
docker-compose up -d
```

Wait for PostgreSQL to be ready:
```bash
docker-compose logs postgres
# Look for: "database system is ready to accept connections"
```

### 4. Create and migrate the database

```bash
rails db:create db:migrate
```

### 5. Start the development server

```bash
bin/dev
```

Visit `http://localhost:3000` in your browser.

## 📖 Usage

### Authentication (Devise)

Devise is installed but no User model is generated by default. Create your own:

```bash
rails generate devise User
rails db:migrate
```

Then access the Devise sign-up/login pages at:
- Sign up: `http://localhost:3000/users/sign_up`
- Sign in: `http://localhost:3000/users/sign_in`

### Authorization (Pundit)

Create policies in `app/policies/`:

```ruby
# app/policies/post_policy.rb
class PostPolicy < ApplicationPolicy
  def create?
    user.present?
  end

  def update?
    user == record.author
  end
end
```

Use in your controller:

```ruby
authorize @post
```

### Testing (RSpec + Shoulda Matchers + Factory Bot)

Create factories for your models:

```ruby
# spec/factories/users.rb
FactoryBot.define do
  factory :user do
    email { Faker::Internet.email }
    password { "password123" }
    password_confirmation { "password123" }
  end
end
```

Write tests using factories:

```ruby
# spec/models/user_spec.rb
require 'rails_helper'

describe User do
  it { should have_many(:posts) }
  it { should validate_presence_of(:email) }
  
  it "creates a user with factory" do
    user = create(:user)
    expect(user).to be_persisted
  end
end
```

Run tests:
```bash
rspec
```

View coverage:
```bash
open coverage/index.html
```

### Email Preview (Letter Opener)

When you send an email in development, it automatically opens in your browser at `http://localhost:3000/letter_opener`.

### Environment Variables

Edit `.env.local`:

```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/myapp_development
MAIL_HOST=localhost
MAIL_PORT=3000
```

Never commit `.env.local`. Use `.env.example` as a template for other developers.

## 🔧 Troubleshooting

### PostgreSQL connection error

1. Ensure Docker is running
2. Start containers: `docker-compose up -d`
3. Wait for PostgreSQL to be ready: `docker-compose logs postgres`
4. Check `.env.local` has correct DATABASE_URL

### Devise initialization error

If you get an encryption key error during setup:
- The template automatically handles this
- If issues persist, check that `config/application.rb` has solid gems commented out

### Port 5432 already in use

Change the port in `docker-compose.yml`:
```yaml
ports:
  - "5433:5432"  # Use 5433 instead
```

And update `.env.local`:
```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5433/myapp_development
```
